# Tamil Nadu Rainfall Map

Streamlit application for downloading TN-SMART rain-gauge observations,
accumulating rainfall over a selected date range, and producing a Tamil Nadu
IDW rainfall map.

## GitHub structure

```text
Tamil-Nadu-Rainfall/
├── app.py
├── requirements.txt
└── data/
    ├── tn_districts.shp
    ├── tn_districts.shx
    ├── tn_districts.dbf
    └── tn_districts.prj
```

## Streamlit Cloud

Main file:
`app.py`

Branch:
`main`

The application needs outbound internet access to TN-SMART.
